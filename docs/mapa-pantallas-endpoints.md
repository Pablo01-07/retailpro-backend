# Mapa Integral de Pantallas y Endpoints de la API: RetailPro

## 2. Matriz de Roles (RBAC)
- **`administrador`**: Acceso total irrestricto, administración de usuarios (22, 23), auditoría (24), activación de versiones de modelos (13), configuración del scheduler (09), ejecución de cualquier proceso batch (07) y umbrales (19).
- **`analista`** (*Analista de Inventarios*): Operación de inventarios, cargas ETL (04, 05), validación de calidad (06), ejecución de pronóstico batch (`/procesos/ejecutar/pronostico`) (07), monitoreo y detalle de procesos (07, 08), reentrenamiento ML (11), ajuste manual de órdenes (16), gestión de alertas (18) y exportación de reportes (21).
- **`jefe_logistica`** (*Jefe de Logística*): Monitoreo ejecutivo de dashboards (14), tendencias (15), planificador de reposición (16), nivel de servicio (17), alertas (18) e historial de reportes (20). Bloqueo HTTP 403 Forbidden ante cualquier mutación, cargas, administración o ejecución de procesos.
